# AI-Based-Music-Composition-Using-Transformer-Network
This project, titled "AI-Based Music Composition Using Transformer Network," is a multimedia AI pipeline designed to enhance user-generated videos by analyzing facial expressions and overlaying background music that aligns with the detected emotions. The core idea behind the project is to automate emotional synchronization between visual content and music, thereby enriching storytelling and viewer engagement. The system utilizes several Python-based libraries and frameworks to accomplish this task. It begins by extracting the audio from the uploaded video and uses Spleeter, a deep learning-based audio separation tool, to isolate the vocal track. Simultaneously, frames are extracted from the video at fixed intervals using OpenCV, and facial emotions are detected through DeepFace, a facial analysis library. The dominant emotion—such as happy, sad, angry, or neutral—is determined based on the frequency of emotions detected across frames. A music file corresponding to that emotion is then selected from a predefined folder structure.

To create a cohesive soundtrack, Pydub is used to loop and trim the selected music to match the video’s duration, and the vocal track is overlaid on top of the emotion-based background music. The final audio is merged back into the original video using MoviePy, resulting in a new video that retains the original dialogue or narration but is musically enriched according to its emotional tone. A Gradio interface makes the application easy to use, allowing users to upload videos and receive processed outputs through a web interface. This integration of vision, audio, and emotion recognition showcases how AI can be leveraged to produce intelligent, emotionally-aware multimedia content.
